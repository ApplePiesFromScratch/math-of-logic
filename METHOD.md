# Method

Three knobs. One loop.

```
V     what values may appear
G     what maps are allowed
theta what counts as accepted, and what happens otherwise
```

```
P / G -> Q
```

Read P under isolation G. Q is the reading. The slash is isolation.
It is division only when G is a rate channel.

## Loop

1. Name V, G, theta in one sentence. If you cannot, you do not have a claim.
2. Run G on V. Every output must land in V.
3. Leave V: fire theta, or run a registered migration and pay the ledger.
4. Score on a listed grid: FORCED-on-cut / EMPIRICAL / DEFER / REFUSE.
5. Grow V before calling two presentations the same G.
6. If a label changes no knob, it is a comment.

## Two honest fixes

Refuse the move, or grow V out loud and pay.

Silent append is the refund button. Every museum patch in this tree
is that shape in harder notation.

## Tiers

- FORCED: enumerated or constructed on the artifact
- FORCED-on-cut: enumerated on a named finite list
- EMPIRICAL: measured, bound stated
- CONDITIONAL: paid only with a named extra assumption
- STIPULATED: a choice, alternative shown
- PRESUMED: citation. Priced at zero. A call to trust.
- OPEN: nobody verifies it here

Citation is a call to trust. Generate when you can.
