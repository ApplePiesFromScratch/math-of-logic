# Construction-error taxonomy

Frequency = how often the error appears as a *load-bearing* step in the models already mapped in this folder (SCIENCE_MAP, DEBUG_MATH, LIFESUPPORT, ACCOUNTING, recover/prior/listed). Not a census of all papers.

```
python3 listed_field.py recover.py prior.py test_affect.py forge.py
```

When you mint a logic or a calculus, scan this list in order. The top rows are the ones that will fire first.

## Seven foundations rows (19-25)

Worth adding. Several overlap #1-#18; they still earn a row because the *symptom* a logician names is the thing a builder will search for.

| proposed | already in | still add because | atlas example |
|---|---|---|---|
| Metalanguage / object collapse | #7 one glyph, #18 slogan | levels, not slots | `=` in `3=3` and in `PASS`; FORCED billed as true |
| Hidden partiality | #10 life support, #13 vacuous | total-looking ink | `/` on Q, `P(A given B)`, rate at `r=0` |
| Iso as id / id as iso | #6 mint-delete, #16 wrap | both directions | `R⊂C` vs dead-slice; wrap complex = split; dual = calculus |
| Axiom smuggling | #2 host, #8 silent μ | named axioms | completeness, infinity, choice, LEM inside `all` |
| Syntax as semantics | #4 combinator-essence, #18 | glyph vs table | polynomial as object; forge table vs word `AND` |
| Circular grounding | #1 primitive-output | definition loop | isolate uses Q because Q makes isolate land |
| Written as executable | #2 host, #8 μ, #25 new | no runner | `∀x∈R`, all histories, Inf modes |

Hidden partiality is the one that fires *inside* a listed V. Rate, quot, inverse, conditional: the notation looks like a total G and θ is the only honest type.

Metalanguage collapse is how FORCED and `A=A` keep coming back after you kill primitive-output: the report uses the machine's `=`.

## Construction checklist (new logic / new calculi)

1. List `Vv` (and `Vr` if you isolate). If you wrote “the reals,” you already have error 2.
2. List G as tables or maps. Forge-scan close **and** emit.
3. Stamp each combinator STIPULATED. Run one other combinator on the same meets (error 4).
4. Isolate is a write. Seed must be in `Vr` (errors 7, 12).
5. Rate / Born / Re / marginal are projects. Keep a line that still has the pair (error 3).
6. `=` is tick / wrap / val / mint. Pick one (error 6).
7. Leftover stays on the page (error 5).
8. New letter ⇒ public μ, then rescan (error 8).
9. Empty domain ⇒ θ, not `all([])` (error 13).
10. Do not file the output as the room (error 1).
