## Errors this model hides because it wrote the ledger

### S1. Default that makes a partial map look total

`isolate(v)` fills seed `1`. On Q, every demo lands. On bits, seed `2` does not.

Fill: keep default 1.  
Unravel: no default. `isolate(v, seed)` always. Partiality is visible.

### S2. Host successor inside Peano

`foundations.py` `S(n) = n+1` uses host `+`. Peano ticks count `S` but the write is still Python int.

Fill: call it Peano anyway.  
Unravel: stamp `S` as STIPULATED host-successor. A listed Peano on `{0,1,2,3}` wrap is a different G.

### S3. `Fraction` as unpaid Q

`from fractions import Fraction` is μ of Q, billed 0.

Fill: “exact rationals.”  
Unravel: every `F(1,2)` is a public letter of `Vq`. Bits have no such import.

### S4. Origin as a string, not a G

Mint is a Python string on `Reading.origin`. Val-eq ignores it. Mint-eq compares strings.

Fill: add a field.  
Unravel: mint is a second pair (output, generator). String is syntax doing semantic work (error 23).

### S5. Gate count as coverage

`verify_all.py` prints `PAID ROWS 153`. That is a count of checks, not of recovered physics.

Fill: bigger suite.  
Unravel: 153 is the meter reading. Einstein still fails `not_einstein_vac`.

### S6. Filter then 100%

Earlier library banners counted only executable rows, then said 100%. Collapse of the catalog (error 14).

Fill: drop citation rows from the headline.  
Unravel: print LIVE and museum on the same page. Never one fraction.

### S7. Dual mix booked as calculus

Readings are `ε²=0`. Complex is another square-rule. The kernel is one mix.

Fill: add `i` to the same class.  
Unravel: two G. Same pair type.

### S8. Ledger billed as joules

Ticks diagnose. Sold as cost-of-reality they are error 1 on the meter.

Fill: more kind labels.  
Unravel: ledger is a stipulated weigh. `L=8` → 450 is a traveler-G, not thermodynamics.

### S9. Wrap implemented with host `%`

Wrap-Leibniz is a different combinator, coded as host ops then fold. Fine if stamped. Error 16 if sold as “the same mix, smaller V.”

Unravel: wrap is G₂. Host is G₁. They differ at one bit pair.

### S10. Constraint booked as discovery

`not_einstein_vac` keeps two reads apart. A later filter `matter=geom` would look like we “found” Einstein.

Fill: add the filter and call it recovery.  
Unravel: the filter is an extra G. Vacuum row stays as the leftover.

### S11. Nouns of the method frozen

`machine`, `write`, `slot`, `combinator`, `θ` start as compression. Frozen, they are furniture (error 1).

Unravel: they are labels for maps. If a sentence cannot point at a runner, drop the noun.

### S12. Self-taxonomy as closed

This file lists S1-S12. Booking that list as complete is error 18.

Unravel: a new row is added when a runner shows a posting this page missed.
