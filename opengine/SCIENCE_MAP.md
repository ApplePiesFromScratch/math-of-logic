## How to read a new paper

1. What V is listed? What is silently R, C, Hilbert, C∞?
2. Where is isolate (chart, prep, condition, mode)?
3. Which combinator (`+`, complex, split, product, wrap)?
4. Which read (rate, η, Born, μ, action)?
5. Which project is then called the system?
6. Where is leftover named vs sent to 0?
7. Where is mint deleted?

If those have answers, you have the machine. The nouns can wait.
