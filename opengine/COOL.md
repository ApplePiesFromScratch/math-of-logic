# Coolest small build

A **no-Inf flight poster** in front of Grok / engineering CI.

Any numeric claim about a vehicle, a model, or a launch (Δv, Isp, loss, accuracy) must post `G V mint writes leftover two-reads` or it is θ. `Isp=Inf` does not ship. `mf=0` does not ship. Empty test set does not ship.

```
python3 cool.py
```

LAND    listed 3306

---

## Why this and not a toy LLM

Elon-shaped itch: first principles, refuse theater, rockets, AI that should not hallucinate a number.

This is the cut box aimed at **the numbers that move hardware**. GEMM still on GPU. The gate is what is allowed to count as a burn, a payload, a “model works.”

Same move as landing burn: if the state is not in V, you do not light.
