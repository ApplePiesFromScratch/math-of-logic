## The debug procedure

For any formula:

1. Circle every numeral. Who minted it? Ticks?
2. Circle every `=`. Tick / wrap / val / mint?
3. Name V for each slot. Same glyph in two slots is often **C**.
4. Name G. If the page says “multiplication is,” expect a hardcoded combinator.
5. Find the project (`f'`, Born, Re, marginal). That is a split pair (**N**).
6. Find leftover sent to 0 (limit, ∞, “exact integral,” renormalization).
7. Find default seed / default host (1, Q, R, C∞). Unpaid landing.

If 1-7 are filled, the line posts. If a noun still does work the G should do, it is off-book.

What does not survive is the opening balance: letters with no generator, hosts called ground, two cuts called one object, leftover called nothing.
