Preface

Why C on Linux The ideas are simple. The machine is real. Use both.

Linux is built in C. The kernel, the shell, the standard library — all C. When you compile a program on Linux you are using tools that were written in the same language, running on an operating system written in the same language, on hardware whose firmware was probably written in the same language. There is a vertical coherence to this that most programming environments do not have.

Formal logic ought to have the same property. A logical system should be something you can build from scratch, inspect completely, and verify without trusting anyone else's framework. C on Linux gives you that. A carrier set — the object this book is about — fits in about two hundred lines of C. No dependencies. No package manager. No runtime. Just a source file, a compiler, and a terminal.

This book is standalone. You do not need to have read anything else. Chapter 1 explains what a carrier set is from the ground up. Chapter 0 gets you set up if you have not compiled C before. Appendix C gives the mathematical reference if you want the formal definitions. Everything else is code that compiles and runs.

C code written to the C99 standard compiles on any Linux system made in the last twenty-five years. The code in this book will still work in 2050.

Who this book is for. Anyone using Linux who is curious about formal logic, wants to understand it mechanically rather than philosophically, and is comfortable with a terminal. You need to know: what a variable is, what a function is, what a loop is. You do not need prior C experience — the language constructs used here are introduced as they appear.

Companion books. Coding Logics in Python covers the same ten ideas in Python. Coding Logics in Rust shows how a static type system enforces carrier properties the C version only checks at runtime. Neither is required to follow this book.

Chapter 0

Setup: Terminal, GCC, First Compile Everything you need installed before Chapter 1.

Opening a terminal

On most Linux desktops: Ctrl+Alt+T. On a server or WSL: you are already there. The dollar sign $ is the prompt. Everything after it is a command you type.

Installing GCC

GCC is the GNU C Compiler. Check whether it is installed:

gcc --version

If you see a version number, you are ready. If you see command not found, install it:

# Debian, Ubuntu, Linux Mint, Pop!_OS: sudo apt install gcc # Fedora, RHEL, CentOS Stream: sudo dnf install gcc # Arch, Manjaro, EndeavourOS: sudo pacman -S gcc # openSUSE: sudo zypper install gcc

Your first C program

Create a file. You can use any editor — nano, vim, gedit, VS Code with the terminal open alongside it. The choice does not matter for this book.

nano hello.c
hello.c
#include <stdio.h>

int main(void) {
    printf("hello, logic\n");
    return 0;
}

Compile it:

gcc -Wall -o hello hello.c

Run it:

./hello
hello, logic

What those flags mean. -Wall enables all warnings. -o hello names the output file hello. Always compile with -Wall. Warnings are the compiler telling you something is likely wrong. Treat them as errors until you understand what they mean.

The flags we use throughout this book

gcc -Wall -Wextra -std=c99 -lm -o carrier carrier.c

-Wextra: extra warnings beyond -Wall.
-std=c99: use the C99 standard (adds bool, better for-loops, and more).
-lm: link the maths library (needed for fabs() in math.h).

A minimal Makefile

A Makefile lets you type make instead of the full compiler command every time. Create it in the same directory:

Makefile
CC     = gcc
CFLAGS = -Wall -Wextra -std=c99 -lm

carrier: carrier.c
	$(CC) $(CFLAGS) -o carrier carrier.c

clean:
	rm -f carrier

.PHONY: clean
The indentation before $(CC) must be a tab character, not spaces. Make is sensitive to this. Most editors insert tabs correctly in Makefiles, but if you see errors, check.

Now make compiles and make clean removes the binary.

Chapter 1

What Is a Carrier? The idea before the code. Read this once, carefully.

A carrier set is a value space plus three operations plus a threshold. That is all. Everything in formal logic — every theorem, every paradox, every system of rules — is an output of those five things.

Here is the classical carrier you already know:

  • Values (V): {0, 1} — false and true
  • NOT: flip the value. NOT(0) = 1, NOT(1) = 0
  • AND: multiply. 1 AND 1 = 1, anything else = 0
  • OR: maximum. max(1, 0) = 1, max(0, 0) = 0
  • Threshold (θ): 1.0 — how much load the system tolerates

From these five choices, the following become unavoidable facts of arithmetic:

  • Law of Non-Contradiction: v AND NOT(v) = 0 for all v in V
  • Law of Excluded Middle: v OR NOT(v) = 1 for all v in V
  • Double Negation: NOT(NOT(v)) = v for all v in V

These are not rules that logicians chose. They follow from the arithmetic. Check them yourself: 0 × (1−0) = 0. 1 × (1−1) = 0. Both zero. Non-Contradiction is just a multiplication fact.

Change one of the five things and different laws become forced. The same mechanism produces every known formal system. This book builds that mechanism in C.

The threshold θ measures load: how much work a reasoning step costs. Simple steps have low load. Deeply self-referential steps have high load. If the load exceeds θ, the system cannot produce a coherent result. This is the mechanical explanation of Gödel's incompleteness theorems: some statements require load that grows without bound, exceeding any finite θ. Not a philosophical mystery — a thermodynamic boundary.

The Liar Paradox (“This sentence is false”) demands a value v where v = NOT(v). In {0, 1} that equation has no solution (it solves to v = 0.5, which is not in the carrier). Add 0.5 to the carrier and the paradox dissolves. One line of code in Chapter 4.

That is the framework. Now build it.

Chapter 2

Hello, Carrier in C Five things. Twenty lines. A complete logic.

The classical carrier in C. Every construct used here is explained inline:

carrier.c
#include <stdio.h>
#include <math.h>   /* fabs() */

/* The value carrier: an array of doubles and its length */
double V[]  = {0.0, 1.0};
int    V_N  = 2;       /* number of values in V */

/* The three operations */
double op_not(double v)             { return 1.0 - v; }
double op_and(double a, double b)   { return a * b; }
double op_or (double a, double b)   { return a > b ? a : b; }

int main(void) {
    int i;
    for (i = 0; i < V_N; i++) {
        double v = V[i];
        printf("v=%.1f  NOT=%.1f  v AND NOT(v)=%.1f  v OR NOT(v)=%.1f\n",
               v, op_not(v), op_and(v, op_not(v)), op_or(v, op_not(v)));
    }
    return 0;
}
gcc -Wall -std=c99 -lm -o carrier carrier.c && ./carrier
v=0.0 NOT=1.0 v AND NOT(v)=0.0 v OR NOT(v)=1.0 v=1.0 NOT=0.0 v AND NOT(v)=0.0 v OR NOT(v)=1.0

The last two columns confirm Non-Contradiction (always 0) and Excluded Middle (always 1). Both laws are arithmetic consequences of the carrier. You verified them by running every value.

C constructs used here

double: a 64-bit floating-point number. Used for all values because later chapters use values between 0 and 1.

double V[] = {...}: an array. V[0] is the first element, V[1] the second.

int V_N = 2: the length of the array. C arrays do not carry their own length; you track it separately.

a > b ? a : b: the ternary operator. Reads: if a > b then a, else b. This is max(a, b).

printf("%.1f", x): print a double with one decimal place.

Chapter 3

Laws Are Tests A for-loop over all values is an exhaustive proof.

To check whether a law holds, test every value. If it holds for all of them, it is forced. One counterexample disproves it. In C this is a for-loop that returns 0 (false) the moment a value fails:

carrier.c (updated)
#include <stdio.h>
#include <math.h>
#define TOL 1e-10    /* tolerance for floating-point comparisons */

double V[]  = {0.0, 1.0};
int    V_N  = 2;

double op_not(double v)           { return 1.0 - v; }
double op_and(double a, double b) { return a * b; }
double op_or (double a, double b) { return a > b ? a : b; }

/* Returns 1 if LNC holds for all values, 0 otherwise */
int check_lnc(double *v, int n) {
    int i;
    for (i = 0; i < n; i++) {
        if (fabs(op_and(v[i], op_not(v[i]))) > TOL) {
            printf("  LNC fails at v=%.4f\n", v[i]);
            return 0;
        }
    }
    return 1;
}

int check_lem(double *v, int n) {
    int i;
    for (i = 0; i < n; i++) {
        double result = op_or(v[i], op_not(v[i]));
        if (fabs(result - 1.0) > TOL) {
            printf("  LEM fails at v=%.4f (OR gives %.4f)\n", v[i], result);
            return 0;
        }
    }
    return 1;
}

int check_dn(double *v, int n) {
    int i;
    for (i = 0; i < n; i++) {
        if (fabs(op_not(op_not(v[i])) - v[i]) > TOL) {
            printf("  DN fails at v=%.4f\n", v[i]);
            return 0;
        }
    }
    return 1;
}

int main(void) {
    printf("Classical carrier {0, 1}:\n");
    printf("  LNC: %s\n", check_lnc(V, V_N) ? "forced" : "FAILS");
    printf("  LEM: %s\n", check_lem(V, V_N) ? "forced" : "FAILS");
    printf("  DN:  %s\n", check_dn (V, V_N) ? "forced" : "FAILS");
    return 0;
}
Classical carrier {0, 1}: LNC: forced LEM: forced DN: forced
C pattern: functions that check a condition return int: 1 for true (success), 0 for false (failure). This is standard C convention. The function also prints diagnostic information before returning 0, so you know where it failed, not just that it failed.

Chapter 4

One More Value Add 0.5 to the array. Watch two laws break.

Add one element to the array. Nothing else changes.

double V[]  = {0.0, 0.5, 1.0};   /* added 0.5 */
int    V_N  = 3;                    /* updated count */

Recompile and run:

make && ./carrier
Classical carrier {0, 0.5, 1}: LNC fails at v=0.5000 LNC: FAILS LEM fails at v=0.5000 (OR gives 0.5000) LEM: FAILS DN: forced

Two laws broke. The operations did not change. Only the value array changed. Let us verify why by hand:

/* NOT(0.5) = 1.0 - 0.5 = 0.5  -- it is its own negation */
/* AND(0.5, NOT(0.5)) = AND(0.5, 0.5) = 0.5 * 0.5 = 0.25  -- not zero */
/* OR(0.5, NOT(0.5))  = OR(0.5, 0.5)  = max(0.5, 0.5) = 0.5 -- not 1 */

The value 0.5 is its own negation under NOT(v) = 1 - v. Multiplying it by itself gives 0.25, not 0. So LNC fails. The maximum of 0.5 and 0.5 is 0.5, not 1. So LEM fails. Double negation still works because 1 - (1 - 0.5) = 0.5.

The laws are arithmetic properties of the value set. Adding a value changes the arithmetic. The same operations produce different laws on different carriers. This is the central fact.

Chapter 5

The Liar Paradox Two thousand years. One for-loop.

The Liar Paradox demands a value v where v = NOT(v). This is called a fixed point of NOT. Finding whether one exists is a linear search:

/* Returns the fixed point if found, -999.0 as sentinel if not */
double liar_solution(double *v, int n) {
    int i;
    for (i = 0; i < n; i++) {
        if (fabs(v[i] - op_not(v[i])) < TOL)
            return v[i];
    }
    return -999.0;  /* sentinel: no solution */
}

void report_liar(double *v, int n) {
    double sol = liar_solution(v, n);
    if (sol > -998.0)
        printf("  Liar: resolved at v=%.4f\n", sol);
    else
        printf("  Liar: no fixed point -- paradox in this carrier\n");
}

int main(void) {
    double V2[]  = {0.0, 1.0};
    double V3[]  = {0.0, 0.5, 1.0};

    printf("Carrier {0, 1}:\n");
    report_liar(V2, 2);

    printf("Carrier {0, 0.5, 1}:\n");
    report_liar(V3, 3);

    return 0;
}
Carrier {0, 1}: Liar: no fixed point -- paradox in this carrier Carrier {0, 0.5, 1}: Liar: resolved at v=0.5000

The equation v = 1 - v solves to v = 0.5. The carrier {0, 1} does not contain 0.5, so there is no solution. The carrier {0, 0.5, 1} does contain 0.5, so the paradox resolves. The Liar is a statement about which value space you are working in, not about truth itself.

A paradox is not a flaw in logic. It is the value space not containing the solution the equation requires. Extend the carrier and it dissolves.

Continuous search

For large or continuous carriers, generate the values in a loop:

/* Generate 1001 evenly spaced values in [0, 1] */
#define N_CONT 1001
double cont[N_CONT];
int i;
for (i = 0; i < N_CONT; i++)
    cont[i] = i / (N_CONT - 1.0);

report_liar(cont, N_CONT);
Liar: resolved at v=0.5000

Chapter 6

The Price of Thinking Every operation costs something. The threshold is the budget.

Maintaining a distinction between true and false requires thermodynamic work. At room temperature, erasing one bit of information costs at minimum 2.87 × 10−21 joules (the Landauer limit). We track this abstractly as load: a non-negative number that accumulates as patterns propagate.

The coherence threshold θ is the maximum load the system can tolerate. A pattern with load above θ cannot settle into a stable state. It is incoherent.

Load combination rules:

  • NOT(P): load unchanged — negation is free
  • AND(P, Q): loads add (L_P + L_Q) — conjunction is expensive
  • OR(P, Q): load takes minimum (min(L_P, L_Q)) — takes the cheaper path
#define THETA 10.0   /* coherence threshold */

/* Check whether a load is coherent */
int is_coherent(double load) {
    return load <= THETA;
}

/* Load combination for AND */
double load_and(double L1, double L2) { return L1 + L2; }

/* Load combination for OR */
double load_or(double L1, double L2)  { return L1 < L2 ? L1 : L2; }

int main(void) {
    double loads[] = {2.0, 3.0, 2.5, 4.0};
    double acc     = loads[0];
    int    i;

    printf("AND chain (theta=%.1f):\n", THETA);
    printf("  Start:  load=%.1f  coherent=%s\n",
           acc, is_coherent(acc) ? "yes" : "NO");

    for (i = 1; i < 4; i++) {
        acc = load_and(acc, loads[i]);
        printf("  Step %d: load=%.1f  coherent=%s\n",
               i, acc, is_coherent(acc) ? "yes" : "NO");
        if (!is_coherent(acc)) {
            printf("  Stopped: threshold exceeded.\n");
            break;
        }
    }
    return 0;
}
AND chain (theta=10.0): Start: load=2.0 coherent=yes Step 1: load=5.0 coherent=yes Step 2: load=7.5 coherent=yes Step 3: load=11.5 coherent=NO Stopped: threshold exceeded.

OR always takes the minimum load, so a chain of ORs never increases beyond the smallest load in the chain. The path of least resistance is always taken. This is why disjunction is structurally cheaper than conjunction.

Chapter 7

Loaded Patterns P = (value, load). The propagation operator in C.

A pattern is a value paired with a load. In C, this is a struct:

/* A loaded pattern: value and load */
typedef struct {
    double value;
    double load;
} Pattern;

/* Constructors */
Pattern pat(double v, double l)  { Pattern p; p.value = v; p.load = l; return p; }
Pattern pat_v(double v)           { return pat(v, 0.0); }  /* zero load */

/* Operations on patterns */
Pattern pat_not(Pattern p) {
    return pat(1.0 - p.value, p.load);   /* load unchanged */
}

Pattern pat_and(Pattern p, Pattern q) {
    return pat(p.value * q.value, p.load + q.load);  /* loads add */
}

Pattern pat_or(Pattern p, Pattern q) {
    double min_load = p.load < q.load ? p.load : q.load;
    double max_val  = p.value > q.value ? p.value : q.value;
    return pat(max_val, min_load);   /* cheapest path */
}

/* The propagation operator: P / G -> Q */
typedef Pattern (*Gradient1)(Pattern);
typedef Pattern (*Gradient2)(Pattern, Pattern);

Pattern propagate1(Pattern p, Gradient1 G) { return G(p); }
Pattern propagate2(Pattern p, Pattern q, Gradient2 G) { return G(p, q); }

int main(void) {
    Pattern P = pat(1.0, 3.0);
    Pattern Q = pat(1.0, 5.0);
    Pattern R;

    printf("P = (%.1f, %.1f)\n", P.value, P.load);
    printf("Q = (%.1f, %.1f)\n", Q.value, Q.load);

    R = propagate2(P, Q, pat_and);
    printf("P / AND -> (%.1f, %.1f)\n", R.value, R.load);

    R = propagate2(P, Q, pat_or);
    printf("P / OR  -> (%.1f, %.1f)\n", R.value, R.load);

    R = propagate1(P, pat_not);
    printf("P / NOT -> (%.1f, %.1f)\n", R.value, R.load);

    return 0;
}
P = (1.0, 3.0) Q = (1.0, 5.0) P / AND -> (1.0, 8.0) P / OR -> (1.0, 3.0) P / NOT -> (0.0, 3.0)
C pattern: function pointers. typedef Pattern (*Gradient1)(Pattern) declares a type for functions that take one Pattern and return a Pattern. You can then pass any such function as an argument to propagate1. This is how C implements first-class functions.

Matches the classical truth table. Vacuous truths (P=0) cost nothing. Forced implications (P=1) carry the load of Q. The only failure: P is true and Q is false.

Chapter 8

The Carrier Struct Five fields. One object. A complete formal system.

Collect the five carrier components into a struct with function pointers for the operations:

#include <stdio.h>
#include <math.h>
#include <string.h>
#define TOL     1e-10
#define MAX_V   256
#define NAME_LEN 64

typedef struct {
    char   name[NAME_LEN];
    double v[MAX_V];
    int    n;
    double (*not_fn)(double);
    double (*and_fn)(double, double);
    double (*or_fn) (double, double);
    double theta;
} Carrier;

/* Build a carrier from its components */
Carrier make_carrier(
    const char  *name,
    double      *vals, int n,
    double     (*not_fn)(double),
    double     (*and_fn)(double, double),
    double     (*or_fn) (double, double),
    double      theta)
{
    Carrier c;
    strncpy(c.name, name, NAME_LEN - 1);
    c.name[NAME_LEN-1] = '\0';
    memcpy(c.v, vals, n * sizeof(double));
    c.n = n; c.not_fn = not_fn; c.and_fn = and_fn;
    c.or_fn = or_fn; c.theta = theta;
    return c;
}

/* Law checks on a Carrier */
int carrier_lnc(Carrier *c) {
    int i;
    for (i = 0; i < c->n; i++)
        if (fabs(c->and_fn(c->v[i], c->not_fn(c->v[i]))) > TOL) return 0;
    return 1;
}

int carrier_lem(Carrier *c) {
    int i; double top = c->v[0];
    for (i = 1; i < c->n; i++) if (c->v[i] > top) top = c->v[i];
    for (i = 0; i < c->n; i++)
        if (fabs(c->or_fn(c->v[i], c->not_fn(c->v[i])) - top) > TOL) return 0;
    return 1;
}

int carrier_dn(Carrier *c) {
    int i;
    for (i = 0; i < c->n; i++)
        if (fabs(c->not_fn(c->not_fn(c->v[i])) - c->v[i]) > TOL) return 0;
    return 1;
}

double carrier_liar(Carrier *c) {
    int i;
    for (i = 0; i < c->n; i++)
        if (fabs(c->v[i] - c->not_fn(c->v[i])) < TOL) return c->v[i];
    return -999.0;
}

void carrier_report(Carrier *c) {
    double liar;

Chapter 10

The Paradox Classifier Four modes. Integer flags. No magic.

There are exactly four ways a formal system can break. C uses integer flags and a struct to classify them:

#define MODE1_LIAR    1
#define MODE2_GOEDEL  2
#define MODE3_RUSSELL 4
#define MODE4_YABLO   8

typedef struct {
    int    flags;           /* bitfield of active paradox modes */
    double liar_solution;   /* -999 if not resolved */
    int    goedel_depth;    /* depth at which load exceeds theta */
} ParadoxReport;

ParadoxReport classify(Carrier *c, double theta, int max_depth) {
    ParadoxReport r;
    double load;
    int    depth;

    r.flags = 0;

    /* Mode 1: Liar -- does NOT have a fixed point? */
    r.liar_solution = carrier_liar(c);
    if (r.liar_solution < -998.0)
        r.flags |= MODE1_LIAR;

    /* Mode 2: Goedel/Turing -- self-referential load diverges */
    load = 1.0;
    r.goedel_depth = -1;
    for (depth = 1; depth <= max_depth; depth++) {
        load *= 2.0;
        if (load > theta) {
            r.flags |= MODE2_GOEDEL;
            r.goedel_depth = depth;
            break;
        }
    }

    /* Mode 4: Yablo -- no seed state (always present) */
    r.flags |= MODE4_YABLO;

    return r;
}

void print_report(Carrier *c, ParadoxReport *r) {
    printf("\nParadox classification: %s\n", c->name);
    printf("  Mode 1 (Liar):    %s",
           (r->flags & MODE1_LIAR) ? "PARADOX" : "resolved");
    if (!(r->flags & MODE1_LIAR))
        printf(" at %.4f", r->liar_solution);
    printf("\n");
    printf("  Mode 2 (Goedel):  %s",
           (r->flags & MODE2_GOEDEL) ? "PARADOX" : "bounded");
    if (r->flags & MODE2_GOEDEL)
        printf(" (diverges at depth %d)", r->goedel_depth);
    printf("\n");
    printf("  Mode 4 (Yablo):   PARADOX (no seed -- universal)\n");
}

int main(void) {
    double v2[] = {0.0, 1.0};
    double v3[] = {0.0, 0.5, 1.0};
    Carrier      classical = make_carrier("Classical",     v2, 2, std_not, std_and, std_or, 1.0);
    Carrier      para      = make_carrier("Paraconsistent", v3, 3, std_not, std_and, std_or, 1.0);
    ParadoxReport r1       = classify(&classical, 1000.0, 20);
    ParadoxReport r2       = classify(&para,      1000.0, 20);
    print_report(&classical, &r1);
    print_report(&para,      &r2);
    return 0;
}

Appendix C

The Mathematics: Reference Formal definitions. For when you want to go deeper.

The three parameters

Every formal system is completely specified by: V (value carrier), Γ (gradient family, the set of available operations), and θ (coherence threshold). Change one and different laws are forced. The mechanism does not change.

Forced laws

A statement is forced in a carrier if it holds for every value in V. Testing is exhaustive: one counterexample disproves, no counterexample across all values proves.

  • Law of Non-Contradiction (LNC): v AND NOT(v) = 0 for all v in V
  • Law of Excluded Middle (LEM): v OR NOT(v) = max(V) for all v in V
  • Double Negation (DN): NOT(NOT(v)) = v for all v in V

Load combination rules

Each pattern carries a load: P = (value, load). Operations combine loads as follows:

  • NOT(P): load unchanged
  • AND(P, Q): load = L_P + L_Q (conjunction is expensive)
  • OR(P, Q): load = min(L_P, L_Q) (takes the cheaper path)

The four paradox modes

Every paradox in formal logic is one of four gradient-overload modes:

  • Mode 1 — Liar: NOT has no fixed point in V (v = NOT(v) has no solution). Resolved by extending V to contain 0.5.
  • Mode 2 — Gödel/Turing: self-referential load doubles at each depth. L(d) = 2⊃d. Exceeds any finite θ. Not resolved by carrier extension.
  • Mode 3 — Russell: the gradient family demands a context larger than the one it defines. Level collapse. Resolved by type stratification (higher axiom debt).
  • Mode 4 — Yablo: no seed state. Construction without a base case. Not resolved by carrier extension. No self-reference required.

DRAS: every quantity is a loaded history

The De-Reification Axiom Standard observes that every measurable quantity is a loaded history q(E) evaluated at energy scale E, not a context-free constant. The fine structure constant is approximately 1/137 at low energies and 1/129 near the Z boson mass. There are no constants. There are only measurements at specific scales.

In formal terms: the carrier V should be written V(E) — a value space that may depend on the scale at which it is evaluated. Most formal systems assume scale independence. Physics abandoned that assumption in the 1970s.

The propagation operator

The complete formal statement: a loaded pattern P = (v_P, L_P) propagates through a gradient field G in context C = (Γ, θ) to produce output pattern Q = P / G where:

  • value(Q) = G applied to value(P) per the operation's value rule
  • load(Q) = G applied to load(P) per the operation's load rule
  • Q is coherent iff load(Q) ≤ θ

All of logic, calculus, and probability theory are instances of this operator on different carriers. This is not analogy. It is the same arithmetic in different value spaces.
